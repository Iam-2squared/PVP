## キャラ・プレイ画面（マップ制作とは独立）

初期6職×男女、計12体のボクセルキャラと、一人称の移動・通常攻撃・ダブル入力1.2倍攻撃を試せる[独立プレイグラウンド](character_playground/README.md)を追加しました。半透明の操作画面、マルチタッチ、練習標的、初期スキルも含みます。

**キャラを動かす場合は `character_playground/project.godot` をGodot 4.6.3で開き、F5で実行**してください。下記の王都用プロジェクトとは別に起動し、マップ生成コード・データは共有しません。攻撃の未定数値は練習用の仮値です。

## 起動とホーム

Godot 4.6.3でルートの `project.godot` を開き **F5** を押すとスタート画面が表示されます。**START**でホームへ進み、レベル・職業・8能力・装備・保有武器・スキルレベル・所持金・次レベルまでのEXPを確認できます。数値は表示確認用のサンプルです。

ホーム中央とスキルツリーに完成したボクセルキャラクターを統合しました。ツリーでは第一6職の男女計12体を切り替えて閲覧し、カードをタップすると職業の詳細と第二職業への分岐を確認できます。ホームはプレイヤー情報の職業・男女設定に従います。

![ホーム](docs/frontend-home.png)

画面の操作・モデルやプレイヤー情報の接続・検証方法は [ホームUIの説明](docs/frontend.md) を参照してください。キャラクターの入力・攻撃を試す独立プロジェクトは、下記の `character_playground/` に残しています。

## 王都の3Dプレビュー

無料の **Godot 4.6.3** で開ける、スマートフォン横画面を想定したボクセル調の一人称歩行プロジェクトです。幅320mの正八角形の城壁と、シンデレラ城の縦長の輪郭を参考にした最高94mの王城を制作しました。王城の21室と階段・回廊を歩いて見学できます。

城下町には住宅・小店舗等304棟と大型施設3棟、35本の街路、12台の屋台を配置しました。街で入れる住宅・公共施設は計11か所です。ギルド、酒場、教会、市場、鍛冶屋、訓練場や庭園を巡れます。

![王都全体](docs/voxel-overview.png)

![王城の外観](docs/voxel-castle.png)

![城下町の路地](docs/voxel-town.png)

1. Godot 4.6.3でこのフォルダーの `project.godot` をインポートする。
2. 王都を見学する場合は `scenes/main.tscn` を開き **F6** で実行する（F5はスタート・ホーム画面）。
3. WASDで移動、画面クリック後にマウスで視点移動、Spaceでジャンプ。**Nで全13か所の見学先、Mで全体図**、Escでマウス解除。
4. タッチ端末では左スティックと右側のドラッグで移動・視点操作。ジャンプ、見学先、全体図は画面のボタンで操作する。

地面は高さ2mの共通石畳と平らな城外用地です。城外には山・海・砂漠・草・岩を配置していません。周辺地形やオンラインPvPなど、下記のゲーム構想にある要素は今後の実装対象です。

生成済みの `generated/kingdom.scn` と `generated/parts/` を読み込むため、実行時に全ボクセルを再計算しません。圧縮済みシーンは分割成分込みで約18.57MiB。城壁・王城・街路・入室施設の物理検証を通過しています。内訳は [計測JSON](generated/world_metrics.json)、操作・再生成・Web版・検証方法は [プレビューの説明](docs/voxel-preview.md)、造形の参考は [建築参考資料](docs/architecture-references.md) を参照してください。スマートフォン実機のFPS・メモリ使用量は未測定です。

## ゲーム構想

スマートフォンの横画面・一人称で遊ぶ、王国を舞台にした常時参加型オンラインPvPゲーム。戦闘、冒険、訓練、転職、ギルド、騎士団で長く遊べる内容を重視し、描画は軽さを優先する。

この文書は、会話で決めたルールと、委任された範囲で作成した現行案を保存したもの。第三・第四職業や隠し職業の具体名、騎士団の細部、ダンジョン名などは、各節に記した設計案・仮案として扱う。未決定事項は末尾にまとめる。ここに記載のない数値・条件を、確定済みとして補完しない。

## 1. ワールドと見た目

- 少し大きめだが広すぎない、正方形のワールドを作る。
- 人数がそろってから始まる試合形式ではなく、途中参加・途中退出する方式。
- 誰かがいる間はワールドが開いている。無人時の保存・休止方法は未定。
- 最初のメインワールドは一つ。城下町と、その周囲から始める。
- 将来はマップ単位で独立したワールドを増やし、強いプレイヤーが次の世界へ進める構想。
- ダンジョンはメインワールドとは別の地下マップにする。
- 表向きの世界観は、国王・王宮・商店・騎士団がある普通の王国。
- 中央に城壁で囲まれた王国を置く。
- 城壁は正八角形を基準とし、王城と城下町を同じ城壁の内側に収める。
- 世界は小さなブロックで形を作るボクセル調3D。人物はNPCを含め、ブロックで組んだ棒人間にする。

北を上にした周辺地形：

```text
             北
       山岳  砂漠  砂漠
       山岳  王国   海
       山岳   海    海
```

- 海：東〜南。
- 砂漠：北〜北東。
- 山岳：北西〜西〜南西。
- 山岳地帯とほかの地形との境界には、普通の野原を挟む。

### キャラクターの見た目

- 棒人間をベースにする。
- 少ない装備で職業の系統が分かるようにする。
- 初期メイジ：黒い薄手のマント。
- 初期戦士：簡素で弱そうな鎧。
- 高精細なグラフィックより、軽さと戦闘中の見やすさを優先する。
- 上位職の具体的な装備デザインは未定。

## 2. 視点と操作

- 基本は横画面・一人称。
- 三人称視点は後回し。
- 左側に、荒野行動のような丸い移動スティック。
- 右側に攻撃ボタン。
- 攻撃ボタンの左下にジャンプボタン。
- ジャンプボタンの上にスキルボタン。
- 極力ボタンを増やさない。

| ボタン | 1回タップ | ダブルタップ |
|---|---|---|
| 攻撃 | 通常攻撃 | 通常より少し強い攻撃 |
| スキル | 選択スキルを切り替える | 選択中のスキルを使用 |
| ジャンプ | ジャンプ | 専用動作は未定 |

通常攻撃は、斬る・突く・矢を射る・小さな火球を飛ばすなど、単純なものにする。現行案では、ダブルタップは同じ挙動・射程で威力1.2倍の一撃。通常攻撃2回が追加で出たり、スキル使用前に選択が切り替わったりしないようにする。

### NPCとの会話

- 会話できるNPCの前では、攻撃ボタンが「話す」に変わる。
- 戦闘中は「話す」に切り替えず、攻撃を優先する。
- 赤丸の攻撃者だけでなく、緑丸・グレー丸で交戦している人も攻撃ボタンを維持する。
- 非交戦時に会話可能NPCへ意図的に先制攻撃する操作は、まだ決めていない。
- 視点移動・照準の具体的な操作も未定。

## 3. 街のPvPと警備

### 戦闘エリア

- 城下町の屋外は原則として戦闘可能。
- 酒場・武器屋など、店の中はセーフティーエリア。
- 店内では攻撃も被弾もなし。
- 店内から外、外から店内への攻撃も通らない。
- 追跡中に店へ入れるかどうかは未定。

### 頭上の丸と正当防衛

| 頭上の丸 | その戦闘での立場 |
|---|---|
| 赤 | 最初に攻撃を仕掛けた人 |
| 緑 | 最初に攻撃され、応戦している人 |
| グレー | 戦闘の途中から参加した人 |

- 緑丸が赤丸を倒しても、正当防衛なので警備に狙われない。
- グレー丸が赤丸を攻撃・討伐するのは援護扱い。
- グレー丸でも緑丸を攻撃したら、その時点で赤丸になる。
- 警備兵への攻撃は、それまでの立場に関係なく即赤丸。
- 騎士団員や近衛隊所属のプレイヤーにも、同じ法と戦闘ルールを適用する。

### 警備の出動・終了・増援

- キルを待たず、先制攻撃の時点で駐屯所から兵士が出動する。
- 兵士はLv100。無敵にはせず、プレイヤーが倒せる存在にする。
- 逮捕・連行ではなく、対象を倒すために攻撃する。
- 対人戦は、当事者のどちらかが死亡したら終了。兵士も帰還する。
- ただし、生存者が兵士とも交戦している場合、その戦闘は続く。
- 追われている本人が死亡するか、警備側から50m離れると追跡終了。
- 警備側を倒した場合は、次の階級が出動する。

```text
兵士 → 騎士 → 隊長 → 副団長 → 団長
```

団長を倒すと、特別な名声「反逆者」を得る。数値の名声との関係、騎士以上のレベル、人数、再出動・復活の条件は未定。

複数の戦闘が重なった際の丸の管理、ログアウト時の扱い、50m離脱の細かな判定は未定。

## 4. 能力値とステータス画面

能力値は次の8種類。以下は現在の役割案であり、具体的な計算式は未定。

| 能力値 | 主な役割 |
|---|---|
| 筋力 | 物理攻撃の威力 |
| 耐久力 | 物理ダメージへの強さ |
| 精神力 | 魔法ダメージ・状態異常への強さ |
| HP | 最大HP |
| MP | 魔法などに使う力の最大量 |
| 回復力 | HP・MPの自然回復 |
| 敏捷力 | 移動や回避の性能 |
| 器用さ | 会心率、弓・罠・道具の扱い |

- 「体力」という表示は使わず、HPにする。
- 魔力は独立した能力値として設けない。
- 自然回復と、回復魔法の威力は同じ概念にしない。
- 魔法の威力を何で計算するかは未定。最大MPを参照する案は出ているが、確定していない。

ステータス画面は、上から次の順。

```text
                ユーザーネーム
                   レベル
                職業〈任意表示〉
                    名声

        筋力      耐久力      精神力      HP
        MP        回復力      敏捷力      器用さ

             8能力の八角形レーダーチャート
```

- 能力値は4列×2行。
- 職業を非公開にした場合、その行を省略する。
- 数値一覧の下に8能力のレーダーチャートを置く。
- チャートの目盛り・正規化方法や、画面内の収まり方は未定。

## 5. 経験値・ポイント配分・訓練

### レベルと経験値

次のレベルに必要な経験値：

```text
現在レベル × 100 EXP
```

| レベルアップ | 必要EXP |
|---|---:|
| Lv1 → 2 | 100 |
| Lv2 → 3 | 200 |
| Lv99 → 100 | 9,900 |
| Lv100 → 101 | 10,000 |

- Lv1から100までの累計は495,000EXP。
- Lv100到達には数か月を想定する。
- 能力値そのものは大きく成長できるようにする。
- 何か月で到達するかは、プレイ時間の想定と経験値報酬を合わせて調整する。
- キャラクター自体の最高レベルは、まだ決めていない。

主な経験値の入手先：

- 冒険者ギルドのクエスト。
- ダンジョンの魔物討伐・踏破。
- プレイヤーキル。
- 週一回の大規模レイド。

PK報酬は「相手が1レベル失った分のEXP」を基準にする。先制攻撃側が3レベル失う場合や、レベル途中のEXPを含めた計算方法は未定。死亡ペナルティ3倍を、そのまま報酬3倍とすることは決めていない。

### ポイント配分と職業補正

- レベルアップで能力値配分ポイントを得る。
- ポイントを8能力に振り分ける。
- 配分したポイントの効果に、職業別の倍率を掛ける。
- 例：戦士の筋力への配分は、ポイント×1.1。
- 第一職業では、指定された1能力の配分効果が＋10％。
- 第二職業では、その職業に指定された2能力の配分効果が各＋10％。
- 初期の職業差は小さく、やり込むほど差が積み重なる。
- 通常転職は成長を引き継ぐ積み上げ式。
- 1レベルで得るポイント量、端数処理、第三・第四職業の具体的補正は未定。

能力値の成長は、自動加算ではなく「ポイント配分＋職業補正＋訓練」を基本にする。

### 訓練場

- 特定の能力値を狙って鍛えられる。
- 各能力の訓練分には、キャラクターレベルに応じた上限を設ける。
- レベルが上がると、訓練上限が広がる。
- 訓練上限と、ポイント配分による成長は別に扱う。
- 訓練上限に達したら、ダンジョンやクエストなどで経験値を稼ぎ、レベルを上げてさらに成長する。
- 訓練の内容、必要時間・費用、上限式は未定。

```text
訓練で今の上限まで鍛える
  → 冒険でEXPを稼ぐ
  → レベルアップ
  → ポイント配分で強化 ＋ 訓練上限が広がる
```

## 6. 死亡・復活・成長の巻き戻し

| 死亡した人 | レベル減少 |
|---|---:|
| 通常・正当防衛側 | −1 |
| 先に攻撃を仕掛けた側 | −3 |

- 下限はLv1。Lv0にはならない。
- 倒されたら、後で決める初期リスポーン地点へ戻る。
- 下がったレベル分について、配分ポイントで得た能力値の増分を取り消す。
- 訓練で増やした能力値は、死亡しても減らない。
- レベル低下で訓練上限を超えた場合、上限が広がるまでその能力を追加訓練できない。
- 一度就いた職業は、死亡で必要レベルを下回っても失わない。
- 例：第二職業でLv100から99になっても、第二職業を維持する。
- 死亡時の途中EXP、未使用配分ポイント、所持品・お金などの扱いは未定。

概念上は「初期能力値＋ポイント配分の成長分＋訓練の成長分」を分けて扱う。死亡時に戻すのは、該当レベルのポイント配分による成長分。

### 隠し職業のルール

- 通常の転職ツリーにつながない、転職ブック専用の別ルート。
- ブックを使う転職は、系統に関係なくレベル・能力値を転職先の初期値に戻し、Lv1から育て直す。
- 通常の死亡で訓練分を保持するルールとは区別する。
- 育て直す価値があるよう、通常職より明確に強い成長率・固有能力を持たせる。
- スキル数は5個。
- 隠し職業でも、セーフティーエリアなどの世界共通ルールは守る。
- ブックの入手先、使用条件、消費の有無、スキル・名声・所持品の扱いは未定。
- 隠し職業も職業名の公開・非公開を選べる。

## 8. 第一・第二職業の戦闘内容（現行案）

ダブルタップは各職共通で、通常攻撃と同じ動作・射程の威力1.2倍。武器がなければ、通常攻撃とダブルタップ攻撃は素手になる。スキル数は、その職業で現在使える合計数。

### 第一職業

| 職業 | 対応武器・通常攻撃 | 配分効果＋10％ | 職業スキル |
|---|---|---|---|
| 戦士 | 剣で斬る | 筋力 | 強撃：力を込めた高威力の一撃 |
| メイジ | 魔法杖から小さな火球を飛ばす | MP | 火炎爆発：狭い範囲を炎で攻撃 |
| 斥候 | 短剣で突く | 敏捷力 | 急所突き：会心が出やすい一撃 |
| 弓使い | 弓で矢を射る | 器用さ | 貫通矢：敵を貫いて直線上を攻撃 |
| 僧侶 | 聖杖から小さな光弾を飛ばす | 精神力 | ヒール：自分か味方のHPを回復 |
| 工匠 | 工具槌で殴る | 器用さ | 投擲爆弾：小さな爆弾で範囲攻撃 |

### 第二職業

| ルート・職業 | 対応武器・通常攻撃 | 配分効果＋10％ | 職業スキル2個 |
|---|---|---|---|
| 戦士→騎士 | 片手剣で斬る | 筋力・耐久力 | 踏み込み斬り：短く接近して斬る／迎撃の構え：正面攻撃を軽減して剣で反撃 |
| 戦士→重戦士 | 大剣を振り下ろす | 筋力・HP | 薙ぎ払い：正面を広く斬る／叩き割り：強打して一時的に敵の防御を下げる |

## 9. スキルの成長

スキル自体にもレベルがある。

| 種類 | スキルEXPを得る条件 |
|---|---|
| 攻撃スキル | そのスキルを使って敵を倒したとき |

## 12. ギルド・騎士団・近衛隊・六英傑

### 組織の区別
